# chest-safe-luck

Additive Safe luck pity on exploded red chests. Explode still happens; the next red open gets +this attempt's vanilla/skill %. Success resets pity. Green chests untouched.

## Needs

1. Moru's fork (`RQ_modding_xsystem4`, `-Dmodloader=true`) — not stock xsystem4 1.0.0
2. `rqmod` apply into a work copy (`rqmod\apply.ps1`)

Local-only git. No remote. Do not push until Moru asks.

Apply discovers this folder as sibling `mods\chest-safe-luck\` next to `rqmod\`.
